What this report cannot tell you

  • Measured half hours only — gaps are not filled or scaled up.
  • Base load = median demand 00:00–05:00 local (912 half hours).
  • Operating hours are as declared (mon-fri 08:00-18:00), not detected from the data; bank holidays count as closed only when listed.
  • Out-of-hours consumption above the overnight base load: an indication of opportunity, not a guaranteed saving — some of it may be needed (cleaning, security lighting, frost protection, refrigeration).
  • A supplier file shows when power was used, not by what. Naming the equipment needs a site visit, sub-metering or the building management system.
  • The header states no unit; values assumed to be kWh per half hour.
  • Period columns count half hours from UK local midnight.
  • Not included in costs: VAT, Climate Change Levy, capacity / availability (kVA) charges, reactive power charges, any separately itemised DUoS / TNUoS / metering charges.
